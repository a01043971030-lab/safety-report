# 정기안전점검 보고서 자동작성

건설공사 정기안전점검 보고서를 샘플 7종의 양식·목차·쪽수(평균 168쪽)대로 자동 작성하고
한글(.hwpx)·워드(.docx)로 내려받는 정적 웹사이트입니다. 서버·DB·빌드 과정이 없습니다.

## 파일 구성
| 파일 | 설명 |
|---|---|
| `index.html` | 사이트 전체 (입력창·미리보기·내보내기, 로고·직인·등록증 등 고정 이미지 포함) |
| `vendor/` | 외부 서버 없이 동작하도록 포함한 라이브러리 (JSZip, html2canvas) |
| `.github/workflows/pages.yml` | main 브랜치에 올리면 GitHub Pages로 자동 게시 |
| `vercel.json` | Vercel로 게시할 때의 설정 |

## GitHub에 올려서 웹에 게시하기

1. GitHub에서 **New repository** → 이름 입력(예: `safety-report`) → **빈 저장소**로 생성
   (README·.gitignore 추가 체크 해제)
2. 이 폴더에서 터미널을 열고 (주소는 본인 저장소로 바꿈)
   ```bash
   git remote add origin https://github.com/내아이디/safety-report.git
   git push -u origin main
   ```
3. 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 선택
4. **Actions** 탭에서 "웹사이트 자동 게시"가 초록색으로 끝나면 주소가 열립니다.
   `https://내아이디.github.io/safety-report/`
5. 이후 `index.html`을 고쳐 `git push` 할 때마다 자동으로 다시 게시됩니다.

## Vercel로 게시하기 (선택)
Vercel 대시보드 → **Add New → Project → Import Git Repository** 에서 위 저장소를 선택하면 끝입니다.
Vercel은 비밀번호 보호(Deployment Protection)를 켤 수 있습니다.



## 보고서 종류 3가지 (거푸집 · 항타기 · 기타)
화면 위쪽의 **보고서 종류** 줄에서 `거푸집 보고서` / `항타기 보고서` / `기타 보고서`를 고릅니다.
종류마다 **같은 양식의 샘플 보고서 5개 이상**(PDF 또는 한글 .hwpx)을 `샘플 불러오기`로 올리면
바뀌지 않는 틀·서식·스타일은 그대로 두고 바뀌는 부분만 입력칸으로 만들어 줍니다.
분석한 양식은 종류별로 이 브라우저에 따로 보관되며(● 표시), 다음에 열면 바로 이어서 쓸 수 있습니다.
`기본 양식(예시)`는 흙막이 지보공 샘플로 만든 내장 예시입니다.

## 샘플 불러오기 (같은 양식 보고서 여러 개로 새 양식 만들기)  ※ 베타
1. 위쪽 **샘플 불러오기** → 같은 양식의 샘플 보고서 **PDF 또는 한글(.hwpx) 5개 이상**(최소 2개)을 **한 번에 10개 이상**도 선택(끌어다 놓기·여러 번 추가 가능) → **분석 시작**
   - PDF와 한글 파일은 섞지 말고 같은 형식끼리. 옛 형식 `.hwp`는 한글에서 `.hwpx`나 PDF로 저장해서 올리세요.
   - **한글(.hwpx) 샘플**로 만들면 결과도 **샘플 서식 그대로인 .hwpx 파일**로 저장됩니다(문단 안에서 바뀌는 낱말만 입력칸). 사진은 첫 샘플 것이 남습니다.
2. 분석이 끝나면 "고정 쪽" 후보가 그림으로 나옵니다. **사진·도면처럼 현장마다 완전히 다른 쪽은 체크 해제** → **이 양식으로 사용**
3. 왼쪽에 **바뀌는 내용만 입력칸으로 자동 생성**됩니다. 입력하면 오른쪽 보고서에 바로 반영됩니다.
   고정 쪽은 샘플 그림 그대로(100%) 유지되고, 사진·도면 등 자료 쪽은 샘플 평균 쪽수만큼 비워 두며 이미지를 올릴 수 있습니다.
4. 완성은 **PDF 저장 / 인쇄**. (학습한 양식은 한글·워드 파일 내보내기를 지원하지 않습니다)
5. 분석한 양식은 이 브라우저에 보관되어 다음에 **학습한 양식 열기**로 바로 쓸 수 있습니다.

한계: 글자만 비교하는 방식이라 표 높이가 샘플마다 크게 다르거나 목차가 필요한 쪽은 자동 처리가 안 됩니다
(목차·세로쓰기 표지는 자료 쪽으로 처리). 새 글자는 샘플 글꼴과 비슷한 글꼴로 표시됩니다.


## 로그인(아이디·비밀번호)과 내 작성본
- 처음 열면 로그인 화면이 나옵니다. **새 계정 만들기**로 아이디·비밀번호(6자 이상)를 만들면, 그 계정으로 작성한 내용과 분석한 양식이 **계정별로 따로** 저장됩니다.
- 위쪽 **내 작성본**에서 지금 화면의 입력 내용을 이름을 붙여 저장하고, 나중에 다시 열거나 삭제할 수 있습니다. (첨부 이미지는 저장되지 않습니다)
- 이 컴퓨터에 로그인 도입 전부터 있던 작업은 **첫 계정을 만들 때** "기존 작업 내용 가져오기"로 옮길 수 있습니다.
- **한계:** 서버가 없는 사이트라서 계정은 *이 컴퓨터의 이 브라우저 안에만* 저장됩니다. 다른 컴퓨터·브라우저에서는 같은 계정을 쓸 수 없고,
  비밀번호를 잊으면 복구할 수 없으며, 비밀번호는 로그인 확인용일 뿐 저장된 내용을 암호화하지는 않습니다(공용 PC에서는 로그아웃).
  여러 컴퓨터에서 같은 계정으로 쓰려면 별도의 서버(DB)가 필요합니다.


## 학습한 양식에서 쪽 글자 직접 편집
- 샘플로 만든 양식의 **표지·목차·제출문·참여기술진 명단** 같은 앞쪽도 샘플 틀 그대로 보이고, 바뀌는 부분은 왼쪽 입력칸으로 만들어집니다.
  (목차·세로쓰기 책등은 입력칸 대신 쪽에서 직접 고칩니다.)
- 왼쪽 입력창 맨 위 **쪽 글자 직접 편집**을 켜면 쪽의 모든 글자를 눌러서 **수정**하고, 지우면 **삭제**, 빈 곳을 두 번 누르면 글상자를 **삽입**합니다.
  편집 내용은 계정에 자동 저장되고 PDF 저장/인쇄에도 반영됩니다.
- 한계: PDF 샘플로 만든 양식은 PDF로만 저장됩니다(한글 파일 출력 불가). 한글(.hwpx) 샘플로 만든 양식은 한글 파일(.hwpx)로 저장·편집됩니다.

## 반드시 알아둘 점
- **공개 주소로 게시하면 `index.html`에 들어 있는 직인·진단기관 등록증·교육수료증 이미지가
  주소를 아는 누구에게나 보입니다.** 저장소를 Private으로 만들어도 GitHub Pages로 게시된 사이트 자체는
  공개됩니다(Enterprise 요금제 제외). 외부 공개를 원치 않으면 Vercel 비밀번호 보호를 쓰거나,
  이미지를 뺀 버전으로 게시하거나, 내 컴퓨터에서 `index.html`만 열어 쓰세요.
- 입력 내용은 서버로 전송되지 않고 사용하는 브라우저에만 자동 저장됩니다.
- hwpx는 한컴 한글에서 열리는지 현장 파일로 먼저 확인하세요. 안 열리면 docx를 한글에서 열어 저장하세요.

## 사용 순서
1. 왼쪽 입력창에 현장별로 바뀌는 내용만 입력 (미리보기에 바로 반영)
2. 제3장 공종 선택 후 사진·도면 이미지를 올립니다 (안 올리면 공백으로 남음)
3. 본문은 클릭해서 바로 고칠 수 있습니다
4. **저장** → 입력 내용을 `.json`으로 보관, **샘플 불러오기**로 이어서 작업
5. **한글파일(hwpx) 받기 / 워드파일(docx) 받기** → 완성 보고서 내려받기
